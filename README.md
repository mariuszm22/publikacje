# Publikacje i analizy

Uniwersalne miejsce na artykuły i analizy z bibliografią źródeł.

## Struktura

- `index.html` — strona główna i katalog publikacji.
- `tv-republika-2026/index.html` — publikacja TV Republika 2026, zatwierdzona 8 listopada 2026.
- `jakub-nadstawny/index.html` — zatwierdzony artykuł o karierze i kwalifikacjach Jakuba Nadstawnego.

## Dodawanie kolejnych artykułów

1. Utwórz osobny katalog z czytelną nazwą artykułu.
2. Zapisz artykuł jako `index.html` w tym katalogu.
3. Dodaj na stronie głównej tytuł, datę, krótki opis i odnośnik do katalogu artykułu.

## Publikacja

GitHub Pages: gałąź `main`, katalog główny `/`. Strona jest statyczna i nie wymaga instalowania zależności ani zewnętrznych usług.

Do repozytorium trafiają wyłącznie zatwierdzone materiały przeznaczone do publikacji. Dokumenty robocze, prywatne protokoły i dane dostępowe pozostają poza repozytorium.
